# Changelog

## 0.1.0
- Accounting engine: sector/instrument classification, TFM, BSM, validation, stock-flow reconciliation
  with revaluation and non-financial acquisition.
- Model language (SymPy), dependency analysis, block-recursive solver, static steady state, stability.
- Simulation: scenarios, comparison, one-at-a-time sensitivity, seeded Monte Carlo.
- NetworkX flow and exposure networks, shock propagation.
- Streamlit dashboard (9 pages), Plotly charts, exports (CSV/JSON/Markdown/ZIP).
- Reference models: SIM, PC (Godley & Lavoie) and a bond-revaluation demonstration.
- Tests, GitHub Actions CI, documentation.
